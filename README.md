# 📊 KPI Dashboard with Gradio

This project allows users to upload a CSV file and automatically generate a KPI dashboard.

The application detects date columns and common business metrics such as sales, traffic, and performance, then generates an interactive chart.

## 🚀 Features

- CSV upload through the interface
- Automatic detection of:
  - Date columns
  - Business metrics such as sales, traffic, and performance
- Automated visualization with Matplotlib
- Simple and portable Gradio interface
